5. PROCEDURAL 3D MODELING

5.1 Main Object Construction

Bangun objek menggunakan Three.js geometry dan custom meshes.

Gunakan berbagai teknik:

- BoxGeometry
- SphereGeometry
- CylinderGeometry
- TorusGeometry
- LatheGeometry
- ExtrudeGeometry
- TubeGeometry
- ShapeGeometry
- BufferGeometry
- Custom parametrical geometry.

Gunakan kombinasi beberapa geometri untuk menghasilkan bentuk yang lebih kompleks.

Dilarang membuat objek kompleks hanya dari kumpulan kubus sederhana.

Bentuk komponen harus memiliki karakteristik fisik yang dapat dikenali.

5.2 Component Modeling

Setiap komponen utama harus dibuat sebagai objek 3D terpisah.

Gunakan THREE.Group untuk mengorganisasi komponen dan subkomponen.

Komponen harus dapat:

- Dipilih secara individual.
- Diberi highlight.
- Disembunyikan.
- Dipindahkan.
- Diputar.
- Diperbesar.
- Dianimasikan.
- Dipisahkan dari assembly utama.

5.3 Material System

Gunakan material berdasarkan benda aslinya.

Contoh:

- Stainless Steel.
- Aluminum.
- Carbon Steel.
- Rubber.
- Glass.
- Plastic.
- Copper.
- Titanium.
- Painted Metal.
- Ceramic.
- Concrete.
- Composite Materials.

Gunakan MeshPhysicalMaterial atau MeshStandardMaterial dengan pengaturan roughness, metalness, transmission, opacity, dan material properties yang sesuai.

Jangan membuat seluruh objek menggunakan material yang sama.

5.4 Visual Fidelity

Objek harus memiliki bentuk yang mudah dikenali.

Perhatikan:

- Silhouette.
- Proporsi.
- Geometri.
- Posisi komponen.
- Sambungan.
- Ketebalan.
- Struktur.
- Detail konstruksi.

Untuk objek nyata yang membutuhkan akurasi khusus, cari referensi teknis atau gambar acuan sebelum membuat model.

Jika menggunakan model eksternal GLTF/GLB, periksa sumber, lisensi, dan kelengkapan model.

Jika referensi tidak tersedia, buat representasi konseptual dan jangan mengklaimnya sebagai model CAD presisi dari produk tertentu.

6. ENGINEERING VISUALIZATION MODES

Sistem harus mendukung beberapa mode visualisasi.

MODE A — ASSEMBLED VIEW

Menampilkan objek dalam bentuk utuh.

Seluruh komponen berada di posisi aslinya.

Kamera melakukan orbit perlahan untuk memperlihatkan objek dari berbagai sisi.

MODE B — EXPLODED VIEW

Memisahkan komponen dari assembly utama.

Setiap komponen bergerak menuju posisi exploded yang sudah ditentukan.

Gunakan GSAP untuk mengatur perpindahan secara bertahap dan terkontrol.

Komponen tidak boleh berpindah secara acak.

Setiap komponen harus tetap memiliki hubungan struktural yang dapat dimengerti.

MODE C — CUTAWAY VIEW

Memperlihatkan bagian internal objek.

Gunakan teknik:

- Component hiding.
- Section geometry.
- Clipping plane.
- Transparent material.
- Selective component visibility.

Tampilkan bagian internal tanpa menghancurkan struktur keseluruhan.

MODE D — INTERNAL WORKING SIMULATION

Memperlihatkan mekanisme kerja komponen.

Contoh:

Sepeda Motor:

- Piston bergerak.
- Crankshaft berputar.
- Connecting rod bergerak mengikuti mekanisme.
- Camshaft berputar.
- Roda berputar.
- Gearbox memperlihatkan mekanisme transmisi.

Mesin Industri:

- Shaft berputar.
- Pompa bekerja.
- Valve bergerak.
- Fluida bergerak melalui jalur pipa.
- Tekanan dan temperatur divisualisasikan.

Sistem Elektronik:

- Aliran energi diperlihatkan melalui jalur rangkaian.
- Komponen elektronik memiliki indikator aktivitas.
- Kipas berputar.
- Distribusi panas divisualisasikan.

Setiap sistem harus menggunakan mekanisme yang sesuai dengan fungsi objek.

MODE E — COMPONENT INSPECTION

Pengguna dapat memilih sebuah komponen.

Kamera secara halus berpindah mendekati komponen tersebut.

Tampilkan:

- Nama komponen.
- ID.
- Fungsi.
- Material.
- Posisi dalam sistem.
- Parameter teknis yang relevan.

7. GSAP ANIMATION SYSTEM

GSAP adalah pengendali utama animasi.

Buat timeline terstruktur untuk setiap mode.

Contoh alur animasi:

TIMELINE 01 — INTRODUCTION

1. Scene fade in.
2. Main object muncul.
3. Camera melakukan cinematic orbit.
4. Object identification muncul.

TIMELINE 02 — EXPLODED VIEW

1. Kamera mendekati objek.
2. Komponen utama mulai terpisah.
3. Subkomponen keluar secara bertahap.
4. Label komponen muncul.
5. Seluruh assembly ditampilkan dalam exploded configuration.

TIMELINE 03 — INTERNAL SIMULATION

1. Kamera bergerak menuju komponen internal.
2. Bagian luar menjadi transparan atau disembunyikan.
3. Mekanisme internal aktif.
4. Komponen bergerak secara sinkron.
5. Indikator sistem berubah mengikuti simulasi.

TIMELINE 04 — FINAL ASSEMBLY

1. Semua komponen kembali ke posisi awal.
2. Kamera kembali ke tampilan utama.
3. Status sistem berubah menjadi NORMAL.

Gunakan:

- gsap.timeline()
- gsap.to()
- gsap.fromTo()
- gsap.set()
- gsap.utils
- Easing functions.

Semua animasi harus halus, memiliki tujuan, dan tidak saling bertabrakan.

Jangan menggunakan animasi acak hanya untuk membuat scene terlihat hidup.

Pisahkan timeline presentasi dari simulasi mekanisme agar keduanya dapat dikontrol secara independen.

Pastikan fungsi reset dapat mengembalikan seluruh posisi, rotasi, material, dan status komponen.

12. PERFORMANCE & RENDERING

Optimalkan performa.

Aturan:

- Hindari polygon berlebihan yang tidak terlihat.
- Gunakan geometry reuse.
- Gunakan InstancedMesh untuk komponen berulang.
- Gunakan shadow map secara efisien.
- Batasi renderer pixel ratio.
- Gunakan requestAnimationFrame untuk render loop.
- Hindari membuat geometry dan material berulang setiap frame.
- Disposisi resource yang tidak digunakan.
- Pastikan resize canvas berfungsi.
- Pastikan render tidak menyebabkan memory leak.

GSAP dan render loop harus terkoordinasi dengan baik.
